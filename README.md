# Phonebook — Terminal-Based Contact Manager

A terminal-based contact management system written in C.
Implements basic search algorithms for fast name-based lookup.

## Features
- Add new contacts (name + phone number)
- List all saved contacts
- Search contacts by name
- Supports up to 10 entries

## How It Works
The program runs a menu-driven loop with 4 options:
1. Add a new contact
2. List all contacts
3. Search by name using linear search
4. Exit

## Getting Started
1. Compile: `gcc telefonrehberiC.c -o phonebook`
2. Run: `./phonebook`

## Tech
- Language: C
- Libraries: `stdio.h`, `string.h`
